# 编辑器翻译

插件使用 Godot 原生 `TranslationDomain`，独立域为 `terrain3d.editor`。
启用插件时，语言取自 `TranslationServer.get_tool_locale()`；不修改游戏的 locale，
也不向 Godot 的全局或内置编辑器翻译域添加词条。修改编辑器语言后按 Godot 提示重启编辑器。
没有对应译文时，控件保留原英文。

`terrain3d.pot` 是编辑器界面词条模板，`zh_CN.po` 是简体中文翻译。
新增语言时复制模板、填写 `Language` 与 `Plural-Forms`，再在插件 `_enter_tree()` 中
把该 `Translation` 加入此域。保持快捷键、`%s`／`%d` 等占位符、换行及原文尾部空格不变。

工具栏、参数条和菜单使用原生控件的自动翻译；运行时拼接数字的消息须先对格式串调用
`tr()`，再格式化。弹出窗口需要显式设置同一个翻译域，因为它们可能被重新挂到编辑器下。
只翻译显示文字；节点名称、参数键、资源路径及工具枚举保持不变。

本批覆盖编辑器工具、笔刷参数、地形菜单、资源面板、目录设置、烘焙及纹理打包窗口。
C++ 资源属性的原生 Inspector 名称和类参考文档尚未完整翻译。
